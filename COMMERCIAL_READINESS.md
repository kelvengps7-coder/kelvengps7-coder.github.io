# Checklist de Prontidão Comercial

Nenhuma etapa abaixo deve ser marcada como concluída sem evidência correspondente.

## Identidade
- [x] site institucional público;
- [x] repositório público separado de ambientes jurídicos privados;
- [x] posicionamento e público‑alvo definidos;
- [ ] domínio próprio;
- [ ] e-mail corporativo no mesmo domínio.

## Produto
- [ ] fluxo principal fechado;
- [ ] demonstração sem dados sensíveis;
- [ ] onboarding mínimo;
- [ ] logs e trilha de auditoria;
- [ ] métricas de qualidade;
- [ ] limites funcionais documentados.

## Segurança e privacidade
- [x] diretrizes públicas de segurança;
- [x] minuta de privacidade;
- [x] minuta de termos;
- [ ] ambiente privado para dados reais;
- [ ] controle de acesso;
- [ ] política de retenção;
- [ ] procedimento de incidente;
- [ ] avaliação dos subprocessadores;
- [ ] revisão LGPD antes de operação comercial.

## Piloto
- [x] estrutura do programa piloto;
- [ ] selecionar 3–5 potenciais participantes;
- [ ] termo de piloto;
- [ ] termo de confidencialidade quando necessário;
- [ ] baseline de tempo/qualidade;
- [ ] instrumento de feedback;
- [ ] critério objetivo de saída.

## Monetização
- [x] hipóteses Solo / Team / Business;
- [ ] entrevistas de preço;
- [ ] disposição de pagar validada;
- [ ] método de cobrança;
- [ ] política de cancelamento;
- [ ] suporte comercial;
- [ ] primeira oferta paga.

## Métricas
- [ ] tempo até valor;
- [ ] tempo economizado;
- [ ] taxa de correção crítica;
- [ ] satisfação;
- [ ] conversão piloto → pago;
- [ ] receita recorrente;
- [ ] churn.

## Regra de lançamento

**Não cobrar por promessa. Cobrar somente quando houver um fluxo repetível que entregue valor mensurável e possa ser operado com segurança e revisão humana.**
